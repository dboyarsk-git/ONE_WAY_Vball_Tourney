SETUP
1. In Supabase, open SQL Editor.
2. Create a new query.
3. Paste ALL of supabase_setup.sql.
4. Click Run.
5. In GitHub, replace your current index.html with this new index.html.
6. Commit changes.
7. Wait for GitHub Pages to deploy.
8. Open the site on computer + phone.
9. Change a team name or score on one device.
10. The other device should update live.
